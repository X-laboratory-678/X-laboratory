# Bundled web fonts

The website bundles the following Google Fonts files locally so GitHub Pages does not depend on a third-party runtime stylesheet:

- Oxygen Mono — SIL Open Font License 1.1
- Roboto — Apache License 2.0
- Roboto Mono — Apache License 2.0

Source catalogue: <https://fonts.google.com/>. The font files are distributed under their respective upstream licenses.
